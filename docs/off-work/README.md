# docs/off-work

This folder holds preserved design and planning notes, mainly for provider work (pricing normalization, built-in catalog, completion integration).

It is **not an authority** and never authorizes implementation. Current decisions live in `docs/architecture.md` and `docs/architecture/`, `docs/roadmap.md`, and `docs/plan/`. Where this folder and those documents disagree, they win.

Contents are preserved for reference and are not deleted or consolidated without the user's explicit authorization.
