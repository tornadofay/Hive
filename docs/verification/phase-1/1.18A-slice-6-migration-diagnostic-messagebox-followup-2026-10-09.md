# Phase 1.18A Slice 6 — SQL Diagnostic and MessageBox Follow-Up

Date: 2026-10-09

## Developer-reported result

The developer reported the full `Hive.Tests` suite passing **783/783** (0 failed, 0 skipped) in 2.8 minutes. Retrying the real Embedded → SQL Server migration still showed:

```text
Error code: hive.persistence.migration-unexpected
Hive persistence data migration could not be completed safely.
```

The developer also requested modal HiveMessageBox error messages instead of the inline diagnostic textbox below the Data Migration workspace.

## Source finding

The previous fix only handled `SqlException` instances reaching `HivePersistenceDataMigrator`. The SQL destination setup/creation path can invoke `HiveDatabaseMigrator.MigrateCoreAsync` first. That service caught exceptions and collapsed them into `hive.persistence.migration-unexpected`, so the outer migration boundary could not recover native SQL metadata. This explains the continued loss of diagnostics; the underlying server-side error has not yet been observed.

## Same-slice changes now on `main`

- Added `HiveSqlServerFailureDiagnostics`, a shared fixed-message mapper for known SQL Server error numbers. Diagnostics contain the operation/endpoint role, configured server/database, SQL error number/state/class, and limited next-step guidance. Raw SQL exception text, statements, connection strings, and credentials are omitted.
- `HiveDatabaseMigrator` now searches the exception's inner-exception chain for a `SqlException`. It returns `hive.persistence.migration-sql-failure` and the curated SQL diagnostic. If no SQL exception is present, the existing `hive.persistence.migration-unexpected` error retains only the exception type; exception message and connection details are not exposed.
- Management preserves those curated diagnostics but continues replacing unrelated technical failures with the generic safe migration message.
- The Data Migration workspace now uses a themed `HiveMessageBox` dialog for endpoint preflight, invalid-configuration, and failed migration results. The dialog contains a short user-facing message and expanded/copyable diagnostic details. The inline diagnostic textbox and footer Copy details button have been removed.
- Added diagnostic mapping coverage for SQL schema migration errors 911 and 4060 and extended the Management sanitization regression. Updated the WinForms UI regression to verify the modal error type and copyable details via a test presenter.
- Updated UI and host/management architecture docs, Current Status, Active Work, and this dated verification record.
