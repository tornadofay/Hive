# Phase 1.18A Slice 6 — Embedded → SQL Server Migration Failure Diagnostic Remediation

Date: 2026-10-09

## Reported failure

After renaming a local SQL Server database, the developer ran the Example Host's Embedded → SQL Server full-data migration and received:

```text
Migration failed: Hive persistence data migration could not be completed safely.
```

The message did not establish the underlying cause. In particular, it did not prove that the rename itself caused the failure. The actual SQL error number remains unknown until the remediated build is run against the affected endpoint.

## Finding

The persistence migrator converted every otherwise-unhandled SQL Server exception to the same generic migration error. Management then sanitized that error to another generic message, and the Example Host's copyable diagnostic contained only the generic message. This obscured whether the issue concerned a renamed/missing database, database access, endpoint resolution, permissions, destination schema preparation, or another SQL operation.

## Same-slice remediation committed to `main`

- The persistence migration boundary now maps SQL Server failures to a bounded, safe diagnostic identifying the source/destination role, configured server/database, SQL error number/state/class, and fixed next-step guidance for recognized error numbers.
- Renamed/missing database, access-denied, authentication, permissions, duplicate-key/schema-object, timeout, and endpoint-resolution errors have explicit guidance.
- Raw SQL exception text, SQL statements, connection strings, and credentials are not included.
- Management preserves only the explicitly curated SQL migration diagnostic across its technical-error sanitization boundary. Other unexpected migration errors retain the generic safe message.
- The Example Host's Copy details text now includes the stable error code.
- Added unit coverage for renamed/missing-database and database-access diagnostics and for the Management sanitization boundary.
- Updated persistence architecture and UI guidance to document the diagnostic contract.
