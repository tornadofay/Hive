# Phase 1.20 Slice 1 — Workspace Foundation — Closure Verification

Date: 2026-10-23

## Outcome

**Phase 1.20 / Slice 1 is closed.** The Workspace is an independent, modeless window (single instance) over an embeddable shell, with Direct LLM and Work Items as modules, a favorites-aware Direct LLM target picker, and a working Example Host page. This closes the slice only; Phase 1.20 remains in progress (Slices 2-4 are not authorized by this closure).

Scope and design: [plan 1.20](../../plan/Phase1/1.20.md), [architecture 5.2](../../architecture/v1-host-and-management.md).

## What the slice delivered

- `HiveWorkspaceContext` (resolves the current Management facade per call, raises `ManagementChanged`), `IHiveWorkspaceModule`, shell `HiveWorkspaceView`, modeless `HiveWorkspaceForm`, and public single-instance `HiveWorkspaceLauncher` under `src/Hive.Host.WinForms/Workspace/`.
- Direct LLM and Work Items converted to modules. `DirectLlmTargetCatalog` applies saved favorites: none saved means all eligible targets; favorites saved means only usable favorites (empty list with guidance when none are usable); a favorites load failure is reported and never broadens the list.
- Example Host: `HiveExampleServices` exposes `ResourceAccessContext` (fixes the earlier example exception); new `Overview / Getting Started / Workspace` page opens the real window; the two inline Workspace pages were removed; the host notifies the Workspace after Settings recomposition.
- Tests: `HiveWorkspaceLifecycleTests`, `HiveWorkspaceLauncherTests`, `DirectLlmTargetCatalogTests`, `DirectLlmConversationTests`.

## Developer-reported verification

- **Build:** whole solution rebuilt successfully under the standing Treat Warnings as Errors configuration.
- **Automated:** `Hive.Tests` **818 passed, 0 failed, 0 skipped** (about 3.4 minutes, .NET 10.0.1). The full suite includes the four focused classes above.
- **Example:** the developer reported that the Workspace opens and everything works as intended. The report was a single overall confirmation and was not itemized per handoff check (favorites filtering, favorites removal, recomposition while open, single-window behavior).

The assistant did not build, run tests, or launch the Example.

## Resolved failures worth keeping

- A first run reported `Workspace / WorkItem Operations / V1 Workspace & WorkItem Operations` failing with `Hive Example service 'ResourceAccessContext' is not available`; the Workspace was not an independent window and the Direct LLM picker ignored favorites. These led to the rescope recorded in the plan.
- Lesson: a view that cancels a lifetime `CancellationTokenSource` in `Dispose` must make `Dispose` idempotent. A second `Dispose` of `HiveWorkspaceView` threw `ObjectDisposedException`; `HiveWorkspaceView` and `DirectLlmConversationView` are now idempotent, covered by `Dispose_IsSafeToCallMoreThanOnceWithLoadedModules`.

## Remaining limitations

- The internals of the Direct LLM and Work Items views are not yet split into presenters and panes; this belongs with the Slice 2 chat redesign.
- Runtime context and WorkItem/job visibility (Slice 3), restart/reload handling and phase closure (Slice 4), and Agent mode (Phase 1.21) are not delivered.
