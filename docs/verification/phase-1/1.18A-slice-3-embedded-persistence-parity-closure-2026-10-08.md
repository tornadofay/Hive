It preserves the shared logical persistence contracts while adding Embedded implementations for the applicable Provider, ProviderAccount, ExecutionTarget, favorites, AgentDefinition, WorkItem/attachments, durable event/snapshot/outbox state, Base-Agent durable work state, and Hive Secret Store boundaries, together with the current schema/migration baseline.

## Verification history

The first developer verification after the Slice 3 implementation reported compilation failures in the Embedded persistence implementation and parity tests. The bounded remediation corrected SQLite parameter typing/nullable GUID handling, Embedded public status accessibility, parity-test API/constructor usage, test-data construction, missing lifecycle-update infrastructure, static/instance command-helper mismatches, and related Embedded Agent Work State issues.

The next developer run compiled successfully but reported **739 tests with 729 passed and 10 failed**. The failures all surfaced as `The Embedded persistence metadata is inconsistent or incomplete.` The root cause was in `EmbeddedPersistenceMigrator.ReadStateAsync`: initialized databases were incorrectly checked for application tables as though they were uninitialized, so valid migrated Hive tables were classified as unexpected. The state check was corrected so unexpected-table validation applies only when neither schema metadata table exists.

The following developer run reported **739 tests with 737 passed and 2 failed**. Both failures were stale test fixtures relative to the authorized Slice 3 schema-15 baseline. The initialization test still expected only migration 1, and the rollback test supplied a one-entry migration catalog that was correctly rejected by the production catalog invariant requiring a complete contiguous catalog through the supported current version. The tests were aligned with the schema-15 baseline without weakening that production invariant.

The final developer verification reported **739/739 passed, 0 failed, 0 skipped**.

The final verified Slice 3 result includes:

- structured-extraction persistence through the shared durable event/snapshot boundary, using the same Embedded event persistence implementation rather than a separate Embedded domain model;

- Embedded SQLite implementations behind the existing persistence/resource contracts rather than an Embedded-specific domain model;
- current Embedded schema/migrations through schema version **15**;
- Provider, ProviderAccount, ExecutionTarget, and ExecutionTarget favorite persistence;
- AgentDefinition persistence;
- WorkItem and immutable attachment persistence;
- durable event and snapshot persistence;
- transactional outbox state and lease/completion lifecycle;
- Base-Agent durable Objective, Memory, Question, and Delegation work-state persistence;

- preserved resource identities, ownership/scope, provenance, lifecycle status, resource versions, optimistic concurrency, deterministic ordering, cancellation, and typed persistence errors within the implemented stores;
- SQLite-specific command/transaction/path behavior isolated inside Hive.Persistence;
- SQL Server implementation retained as the regression/reference backend;
- focused Embedded parity coverage integrated into the authoritative `Hive.Tests` suite.
