## Verified host/configuration behavior

- Hive Settings is the normal global package configuration center.
- Saved persistence configuration is consumed by the host composition boundary.
- SQL-password bootstrap material is kept outside the target Hive database and separated from the Hive resource Secret Store.
- Provider, ProviderAccount, ExecutionTarget, and AgentDefinition configuration is authoritative Management state.
- AgentDefinition may reference an existing ExecutionTarget without duplicating target configuration.
- Persistence changes safely recompose the host service graph while preserving a usable current graph when replacement fails.
- Resource-only configuration changes refresh without unnecessary persistence reconstruction.
- The configured Agent operation resolves the persisted AgentDefinition → ExecutionTarget → ProviderAccount → Provider relationship through the existing Management/Coordination boundaries.
- Retired/inactive configured resources are rejected explicitly.
- Credentials and bootstrap secrets are not exposed through configured Agent Example output.
- The Example Host exposes the normal Settings surface and configured Agent scenario.
